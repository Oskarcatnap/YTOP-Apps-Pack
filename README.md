# 🍿 YTOP Apps Pack
**You Try Open Popcorn** — An experimental ecosystem of applications and games.

## 🚀 What's Inside?
* **YTOP-Clicker (Python)**: Your first popcorn factory delivered as a standalone EXE. 
* **YTOP-Core**: More apps coming soon to the ecosystem!

## 📥 How to Run
1. Go to the [Releases](https://github.com/Oskarcatnap/YTOP-Apps-Pack/releases) section.
2. Download the latest `.exe` file.
3. Open and start popping!

## 🛠 Technologies
- **Python**: Main interface and clicker logic.
- **Multi-Language Support**: Built to integrate various programming languages in one pack.
